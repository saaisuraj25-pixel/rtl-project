# RTL projects

Two digital design projects in Verilog:

- [riscv-pipeline](riscv-pipeline) - 5-stage pipelined RISC-V processor (RV32I)
- [async-fifo](async-fifo) - asynchronous FIFO for clock domain crossing

Each folder has its own README with how it works and how to run the tests.

Tools: Icarus Verilog or Verilator, GTKWave, Python 3 (only for the random test generator).

References:
- D. Harris, S. Harris, *Digital Design and Computer Architecture: RISC-V Edition* (pipeline and hazard unit)
- C. Cummings, *Simulation and Synthesis Techniques for Asynchronous FIFO Design*, SNUG 2002 (FIFO)
- *The RISC-V Instruction Set Manual, Volume I: Unprivileged ISA*
